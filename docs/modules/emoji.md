# Emoji picker

`Super+;` (preset `emoji-picker`, `qs ipc call emoji toggle`) opens a search box and a grid of emoji; **Enter or a click types the emoji
into the window that had the focus** with `wtype`. Added 2026-10-21, replacing the Omarchy picker (`omarchy-shell shell toggle
omarchy.emojis`) from the owner's old setup (`keybindings.md`, "Imported from the old Omarchy setup").

## How it works

- Module `modules/emoji/Emoji.qml`, built like the launcher: a full-screen transparent overlay window with exclusive keyboard focus,
  created only while open (`LazyLoader`); a click outside or Esc closes it. Search: every word of the query must appear in the
  emoji's name. Arrow keys move in the grid, Enter picks, hover selects, the highlighted emoji's name shows under the grid.
  With an empty query the 16 most recent come first, then everything in the Unicode order. Recents are kept in
  `Quickshell.statePath("emoji-recent.json")`.
- Typing: the picker closes first (the compositor then hands the focus back to the previous window), and 150 ms later runs
  `sh -c 'wtype "$1" || wl-copy "$1"' sh EMOJI`. The emoji is an argument, never part of the shell text. **If `wtype` is missing
  the emoji is copied instead**, so Ctrl+V still works. `wtype` types through Wayland's virtual-keyboard protocol.
- Data: `modules/emoji/emoji.json` (about 56 KB, 1,914 emoji in 9 groups), generated by `scripts/build-emoji-data.py` from the
  official `emoji-test.txt` (Unicode emoji 18.0): fully-qualified emoji only, the five skin-tone variants of each left out (the base
  emoji stays), and **any emoji whose codepoint the installed Noto Color Emoji cannot draw is dropped** (nine of the newest, at
  `noto-fonts-emoji` 2.051), so the picker never shows an empty box. Run the script again after the font package updates.
  No package is needed for the data.
- Test hooks: `qs ipc call emoji status` (open, count, recents), `qs ipc call emoji pick TEXT` (types TEXT as the picker would).

## Install

`sudo pacman -S --needed wtype` (10 KiB, depends on libxkbcommon and wayland, already present; installed by the owner on
2026-10-21). Fonts: `noto-fonts-emoji` was already installed.

## Verified and not

- Verified 2026-10-21: the module loads 1,914 emoji; the picker opens from the Hyprland key route (`exec_cmd`) and closes; the grid
  renders in colour with the first emoji highlighted and its name shown (screenshot); the data generator drops the nine
  undrawable emoji.
- Verified 2026-10-21 after `wtype` 0.4 was installed, end to end with `wtype` driving the picker itself: a scratch terminal
  (`cat > file`) had the focus, the picker opened over it, `wtype "avocado"` filled the search (one match), `wtype -k Return`
  picked it, the picker closed, and the scratch terminal received the bytes `f0 9f a5 91` (🥑) and a newline; the recents file
  gained the emoji. The test emoji were cleared from the recents afterwards.
- Not verified: a real mouse click on a cell, the arrow keys and hover by hand, the clipboard fallback when `wtype` is missing
  (the shell snippet is simple but was not run, to keep your clipboard), typing into an XWayland window, a second monitor.
