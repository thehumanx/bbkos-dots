# Module: dotfiles (GNU Stow)

Applied: 2026-10-18 (Task 3 for fish/kitty, Task 6 for Hyprland). Repo location: `~/.local/share/bbkos/repo/dotfiles` (same git repo as the docs, so the future bbkOS agent skill reads one source). See `dotfiles/README.md` for usage.

## Why Stow

| Option | Pros | Cons |
|---|---|---|
| **GNU Stow** (chosen) | Plain symlinks, no daemon, nothing to learn, transparent for people and agents | No templating or secrets handling |
| chezmoi | Templates, per-machine config, secrets | More tooling than one machine needs |
| Bare git repo in `$HOME` | No extra tool | Easy to commit the wrong thing; opaque |

## Linked packages

All but `quickshell` are linked with `--no-folding`; the full table is in `dotfiles/README.md`. The cursor set is its own package (`cursor`, `~/.local/share/icons/Afterglow-cursors`, 10 MB, linked file by file because the directory also holds Stow's links): `hyprland.lua` sets `XCURSOR_THEME`/`HYPRCURSOR_THEME` to `Afterglow-cursors` and both sizes to 24. The environment applies at the next login; a reload does not change the cursor of the running session.

## Changes made when moving `hyprland.lua` into the repo

Original saved at `~/.config/hypr/hyprland.lua.bak-bbkos` (outside git). Only two edits:

1. Removed `hl.config({ autogenerated = true })` (the "autogenerated" warning banner).
2. Removed the `hyprland.start` autostart of `gnome-keyring-daemon` (redundant: `pam_gnome_keyring` and the user socket handle it; see `session.md`).

Left alone on purpose until their replacements exist: `fileManager = "dolphin"` (Task 7 installs thunar) and `menu = "hyprlauncher"` (Task 8 provides the Quickshell launcher).
